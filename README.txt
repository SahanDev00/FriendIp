FRIEND / VISITOR FRONTEND
1. Open app.js and replace https://YOUR-BACKEND.onrender.com with your deployed Render backend URL.
2. Deploy this folder to Netlify (Add new site -> Deploy manually, or connect its GitHub repository).
3. Copy the Netlify site URL. Set it as PUBLIC_SITE_URL in Render and include it in ALLOWED_ORIGINS.
4. Generate a link in the admin panel and share it with your consenting tester.
The visitor page clearly explains that an approximate IP-based location lookup is recorded. It does not request GPS.
